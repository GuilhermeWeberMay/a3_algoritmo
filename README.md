# Sistema de Contas a Pagar

Projeto desenvolvido para a unidade curricular **Algoritmos e Programação**, da Universidade do Sul de Santa Catarina (UNISUL), como parte da atividade A3 – Desempenho de Compreensão.

O objetivo é desenvolver um sistema para auxiliar no controle financeiro de uma empresa, permitindo o gerenciamento de contas a pagar e o acompanhamento de suas situações.

## Funcionalidades

- **Cadastro de contas:** inclusão, alteração, consulta e exclusão de contas a pagar.
- **Controle de pagamentos:** registro de pagamentos parciais ou totais, com atualização do saldo devedor.
- **Relatório de contas a pagar:** listagem de contas por período, ordenadas pela data de vencimento.
- **Relatório de contas vencidas:** identificação de contas em atraso em determinado período.
- **Balanço de despesas:** apresentação das despesas da empresa em um período selecionado.

## Objetivos do projeto

Aplicar conceitos de lógica de programação e algoritmos na resolução de um problema prático, utilizando sub-rotinas (procedimentos e funções), vetores e menus interativos para organizar os dados e facilitar a utilização do sistema.

O projeto é desenvolvido em grupo, seguindo os requisitos propostos na atividade acadêmica.
